## 🌈 Book III — Gender-Inclusive STEM Standards

**Six Research-Backed Practices (NGCP Brite 2026 + 30by30 + CREST + Springer 2026):**

1. **Belonging & Relevance** — "STEM is for me, and it connects to my world."
2. **Investigation** — "I ask questions and design ways to answer them."
3. **Normalized Struggle** — "Getting stuck is part of the work. I know how to get unstuck."
4. **Stereotype Challenge** — "STEM people look like me, live like me, come from everywhere."
5. **Collaborative Work** — "We build better together."
6. **Diverse Role Models** — "I see my future self in the people I meet."

**Evidence Base:** NGCP Brite Practices (2026), 30by30 K-12 Guide, CREST Awards, Springer 2026 (Dahn et al. — online mentoring + in-school clubs = highest impact when bridging quality is high).

## 👩‍🔬 Book V — Mentorship & Role Model Registry

**Springer 2026 Weighted Composite:**
```
Final Score = 0.35×Identity + 0.25×Pathway + 0.40×Bridging
```
*Identity* = Cosine similarity on gender/ethnicity/geography/hobbies/challenges  
*Pathway* = Jaccard overlap between mentor journey & mentee aspirations  
*Bridging* = Coordinator availability + platform + cadence + language

**Role Model Requirements (Brite Practice 4):** Early life + hobbies + challenges + perseverance + non-linear pathway + hobbies outside STEM.
