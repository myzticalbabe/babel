# Struggle Journal — Template & Facilitator Guide

> **Soul Forge Principle:** "Getting stuck is part of the work. I know how to get unstuck." — Brite Practice 3: Normalized Struggle

---

## Purpose

The Struggle Journal makes struggle **visible, documented, and celebrated**. Every learner gets one. Every session uses it. It's not a worksheet — it's a growth record.

---

## Facilitator Guide

### When to Use
- **Every session** — during build/test/debug phase
- **Minimum 5 minutes** protected time
- **Not homework** — done in session, facilitated

### The Three-Before-Me Protocol
Before learner brings journal to facilitator:
1. **Self** (30 sec): Re-read stuck point, try one more thing
2. **Peer** (1 min): Ask elbow partner "What would you try?"
3. **Resource** (1 min): Check diagram, glossary, previous journal
4. **Facilitator** — now bring journal

### Facilitator Response Moves

| Learner Entry | Facilitator Response |
|---------------|---------------------|
| "It doesn't work" | "What exactly happens? 'LED won't light' not 'it's broken'" |
| "I tried everything" | "List three things you tried. What did each tell you?" |
| "I give up" | "What's the smallest next step? Let's try just that one." |
| "I don't know what to try" | "Three before me: self → peer → resource → me. Where are you?" |
| Strategy worked | "Document it! What would you tell someone else with this stuck point?" |

### Celebrating Failures
**Script:** "That attempt? That's data. You just learned [specific thing]. Write it down — future you needs this."

## Identity Check Prompts (Rotate)

| Session | Prompt |
|---------|--------|
| 1 | "How does this struggle connect to a time you solved something hard before?" |
| 2 | "What would you tell your past self about this stuck point?" |
| 3 | "How does this connect to who you want to become?" |
| 4 | "What would you tell someone else who gets stuck here?" |
| 5 | "What part of your culture/family/hobbies helps you here?" |
| 6 | "If you mastered this, what would you build for your community?" |

## Tracking & Patterns (Facilitator View)

### Weekly Struggle Journal Review (10 min)
1. **Scan** all journals for patterns
2. **Note** common stuck points → adjust next session materials
3. **Identify** learners with 0 strategies → targeted check-in
4. **Celebrate** growth edges publicly (anonymized)

### Struggle Journal Analytics (Per Unit)
| Metric | Target | Action if Below |
|--------|--------|-----------------|
| Avg strategies per learner | ≥2 | Model more strategies, pair with high-strategy peer |
| Identity check completion | 100% | Private check-in, offer scribe/dictation |
| "Didn't work" → next strategy | ≥80% | Teach "partial success = data" explicitly |
| Peer strategy use | ≥50% | Explicit "ask peer" protocol practice |

## Struggle Journal as Portfolio Evidence

### Mastery Indicators
| Level | Struggle Journal Evidence |
|-------|---------------------------|
| **Exploring** | 1 entry, facilitator-scribed, "I don't know" |
| **Developing** | 2+ entries, self-written, 1 strategy documented |
| **Mastering** | 3+ entries, 2+ strategies, identity connection clear |

### Identity Bonus Qualification
Learner earns **+5% mastery** when journal shows:
- ☐ Stem self-connection ("I am becoming an engineer who...")
- ☐ Future self named ("I see myself as...")
- ☐ Struggle as growth ("This taught me...")
- ☐ Community impact named ("This helps my abuela by...")

## Accessibility Adaptations

| Need | Adaptation |
|------|------------|
| **Writing difficulty** | Scribe (peer/facilitator), voice-to-text, drawing + labels |
| **Language** | Bilingual template (EN/ES), picture prompts, native language OK |
| **Motor** | Large print, raised lines, digital form, verbal dictation |
| **Cognitive** | Sentence starters: "I got stuck when...", "I tried...", "Next I will..." |
| **Visual** | High contrast, large font, tactile stickers for check boxes |

## Struggle Journal as Family Connection

### Take-Home Prompt (End of Unit)
> **Family Struggle Share:** "Tell your family about your hardest stuck point this unit. What did you try? What worked? What did you learn about yourself?"

**Return:** Optional family signature + one-word description of learner's persistence
